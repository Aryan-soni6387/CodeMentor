# 🚀 CodeMentor

An AI-powered DSA Preparation and Interview Practice Platform that helps students track coding progress, analyze strengths and weaknesses, receive AI-powered code reviews, and prepare for technical interviews through intelligent interview simulations.

---

## 🌟 Features at a Glance

* 📊 DSA Progress Tracking
* 🔥 Streak & Consistency Monitoring
* 🤖 AI Code Review
* 💬 AI Chat Assistant
* 🎤 AI Technical Interviews
* 📈 Performance Analytics
* 📝 Problem Notes System
* 🏆 Leaderboard & Rankings
* 🎖️ Badge & Achievement System
* 📚 A2Z DSA Sheet Tracker

---
